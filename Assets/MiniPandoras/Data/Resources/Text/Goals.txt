# Goals
# 메인 임무의 제목과 설명. id는 Goals의 상수와 같다.

== goal.surviveHillia.title
text			낯선 땅 힐리아에서 살아남는다
== goal.surviveHillia.detail
text			처음 보는 땅에 떨어졌다. 주변을 살피며 앞으로 나아가자.

text			북쪽의 뱀성으로 간다
== goal.goToSnakeCastle.detail
text			랑이 북쪽으로 가자고 했다. 들판 위쪽 길을 따라 뱀성으로 가자.

== goal.fleeUpTheCastle.title

== goal.fleeUpTheCastle.detail
text			병사들에게 쫓기고 있다. 위층으로 올라가는 계단을 찾아 도망치자.

== goal.findHidingPlace.title

== goal.findHidingPlace.detail
text			마을에 순찰병이 돌고 있다. 눈에 띄지 않게 숨을 곳을 찾자.

== goal.goToTrainStation.title

== goal.goToTrainStation.detail

== goal.findTheHarbor.detail

== goal.boardTheWestShip.title
